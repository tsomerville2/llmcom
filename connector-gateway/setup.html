Start here on your Mac, in your browser. Keep your phone aside until the last step.

Choose the app you use on your phone.

1 · Mac → Terminal

Get your pairing code

Open Terminal on your Mac. Copy this command, paste it into Terminal, and press Return.

curl -fsSL https://llmcom-connector.fly.dev/install.sh | sh -s -- --client openai --open

This installs or updates LLMCom and opens a private browser page with a Copy pairing code button. Keep that private page open. You will copy the code when ChatGPT asks you to connect.

LLMCom is already installed
llmcom phone myphone --client openai

Run this whenever you need a fresh code. Codes expire after 10 minutes.

2 · Mac → Browser → ChatGPT

Add your private LLMCom connection

LLMCom is not in the public plugin directory yet. Searching for it will show “No plugins found.”

We will use ChatGPT’s Add menu instead. Keep this guide open beside ChatGPT.

Open ChatGPT — sign in first ↗

Use the same account as your phone. If this opens a browser where you are signed out, click Log in there, or open https://chatgpt.com/plugins in the browser where you already use ChatGPT.

What do you see in ChatGPT?

Sign in before continuing

Click Log in in ChatGPT’s top-right corner. Finish signing in, then return here and choose Add or LLMCom under Installed. Do not search the public directory.

Create your private plugin

  1. In ChatGPT, click Add beside the search box, then Add custom MCP server.
  2. Enter LLMCom in Name. Paste this into Server URL:
    https://llmcom-connector.fly.dev/mcp
  3. Leave Authentication on OAuth. Review the notice, check I understand and want to continue, then click Create as a plugin.
  4. Click Continue to LLMCom if prompted. Our website opens at llmcom-connector.fly.dev.

Now use your pairing code

Return to the private LLMCom for ChatGPT and Codex tab opened by Terminal. Click Copy pairing code. Back on our Fly.io sign-in page, paste it into One-time pairing code and click Connect this Mac’s LLMCom. Finish installing in ChatGPT if prompted.

If your code expired, run llmcom phone myphone --client openai again for a fresh code.

Use your existing LLMCom plugin

Click LLMCom under Installed in ChatGPT’s left sidebar. If it asks you to connect, click Connect and use the pairing code from your private setup tab on our Fly.io page. If it already says connected, continue to the phone test below.

Check the account and screen

Make sure you are signed in at https://chatgpt.com/plugins in your Mac browser. The signed-in screen we verified has an Add menu beside the search box. If your account does not show it, this setup path is not available on that screen. Stop here and share a screenshot; searching for LLMCom will not fix it.

Your pairing code belongs only in our Fly.io sign-in page, never in OpenAI’s password box. This public guide contains no private code.

Now open ChatGPT on your phone → Codex → your coding chat. Select LLMCom in the chat’s plugins/tools menu, if available, then say or type:

Use LLMCom to join myphone as my-phone, say hello, then listen for replies.

If LLMCom is missing from that phone chat, stop here. Tell us which screen you see. Phone Codex voice support is still being verified; desktop pairing alone does not prove it works there.

Or do it yourself · 1 · Mac Terminal

Run one command.

curl -fsSL https://llmcom-connector.fly.dev/install.sh | sh

Paste into Terminal and press Return. Setup prepares your Mac and prints the next steps. To use this illustrated browser guide, run llmcom phone myphone to open your private page with Copy URL and Copy Authorization value.

Closed that private page?
llmcom phone myphone

Run this in Terminal to reopen it. Claude does not use a pairing code.

2 · Mac browser · Same Claude account as your phone

Click Add → Add custom connector.

Open Claude Connectors ↗
3 · Claude’s first form

Name it. Paste your URL. Continue.

  1. Name: LLMCom Remote.
  2. On your private setup page, click Copy URL.
  3. Paste into MCP server URL, then click Continue.
4 · Claude’s authentication form

Choose No sign-in, then add your key.

Under Request headers, add a row. Header name: Authorization. Click Copy Authorization value on your private page and paste into Value. Leave Required checked, then click Add.

The sign-in warning is expected when using a key.

I don’t see Request headers

Stop here—this setup path cannot finish on that screen. Our live check found that some Claude accounts show no Request headers field, even under Advanced. Do not click Add with the key missing. The screenshot below shows this blocked case; it is not a successful connection.

5 · Mac coding chat → Phone Claude

Say hello. Hear a reply.

In the coding conversation on your Mac:

Run llmcom join myphone in this conversation. Reply when my phone says hello.

On your phone, open a new Claude chat, enable LLMCom Remote, and say:

Use LLMCom Remote to join myphone as my-phone, say hello, then listen for replies.

You’re connected when the Mac receives your hello and the phone receives its reply. Try text first, then voice.

What to expect

Keep your Mac awake and online. Listening lasts up to 60 seconds per active call and returns early when a message arrives. It does not wake an idle chat.

Each person sets this up on their own Mac and account. Your friend gets their own private workspace. Never share your pairing code or private setup page.

These are custom connectors, not verified public directory listings.
