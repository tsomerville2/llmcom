# LLMCom rescue data

Data-only companion to llmcom 0.2.0. Installed automatically with the main package. Contains remaining checksummed parts of its public Apple Silicon rescue archive, preserving third-party code and licenses inside that archive. Normal installs use upstream; `llmcom setup CHANNEL --offline` explicitly selects this backup.

See https://github.com/tsomerville2/llmcom for provenance, package inventory, upstream licenses and instructions.
